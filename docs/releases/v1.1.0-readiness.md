## Known Limitations

- GitHub Copilot has no controlled runtime-loading evidence. Its IDE surface
  offers no headless, read-only invocation, so promotion to Primary would
  require a manual editor probe that this release did not perform.
- The recorded Codex and Claude Code probes were run against `codex-cli
  0.145.0` and Claude Code `2.1.218`. The local machine now reports
  `codex-cli 0.146.0` and `2.1.220`. The evidence was not re-run against those
  newer versions, and this release makes no claim about them.
- Path-scoped `.github/instructions/*.instructions.md` behavior is untested and
  intentionally out of scope.
- All reference evaluations remain owner-authored. No external adopter evidence
  exists for any release so far.
- Validator semantic review remains manual for lifecycle freshness, decision
  quality, and supplement ownership.
- The first run of this audit matched its own privacy scan, because a
  verification row was named with the words the scan searches for. The label
  was renamed rather than adding a scan exclusion, so the scanned surface is
  unchanged. `docs/releases/TEMPLATE.md` records the rule.
- `README.zh-CN.md` is a human-readable translation. It is not validated for
  semantic drift against the English README by any automated check.
