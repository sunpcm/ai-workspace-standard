## 已知限制

- GitHub Copilot 没有受控运行时加载证据。其 IDE 侧没有 headless 只读调用方式，
  升入 Primary 需要一次人工编辑器探针，本版本未执行。
- 已记录的 Codex 与 Claude Code 探针针对 `codex-cli 0.145.0` 与 Claude Code
  `2.1.218`，而本机现为 `0.146.0` 与 `2.1.220`。证据未针对新版本重跑，本版本
  也不对新版本作任何声明。
- 译本（如 `README.zh-CN.md`）可能与英文原件产生语义漂移。没有任何自动检查
  比对两者含义，只能靠在同一次改动中同步更新。
- 语言边界守卫检查的是「有没有中文」，不是「该不该是中文」。它能拦住就地翻译
  契约文档，但无法判断某份新文档是否被错误地声明为豁免项。
- 验证器的重复句检测对已转中文的文档实际失效。但本版本转中文的文档
  （`docs/roadmap.md`、`docs/vision.md`、readiness、TEMPLATE）本就不在
  `_mapped_files` 覆盖范围内，因此没有实际检测能力损失。
- 至今没有任何外部采用证据，全部参考评估均由 owner 撰写。
- 验证器的语义评审仍需人工：生命周期新鲜度、决策质量、supplement 归属。
