## Stable v1 Surface

- Four scopes: Global, Workspace, Repo, and Experiment.
- Project, Decisions, Handoff, and Experiment canonical roles.
- Thin agent adapters as projections from canonical documents.
- Routing-only adoption mapping version 1 with primary, supplements, lifecycle
  states, and open adapter entries.
- Dependency-free, read-only template and adoption validation.
- Optional evidence-backed cross-agent checkpoint protocol.
- Primary compatibility policy for Codex and Claude Code, with an open
  extension contract for other tools.

Changes that break this surface require the major-version process in
`docs/versioning.md`.

## Known Limitations

- Validator semantic review remains manual for lifecycle freshness, decision
  quality, and supplement ownership.
- Compatibility evidence applies only to the recorded tool versions and probe
  configurations.
- AEWS provides checkpoint continuity, not real-time presence, locking,
  transcript sync, or orchestration.
- Hooks, MCP catalogs, memory runtimes, policy engines, generators, and package
  distribution remain outside the stable core.
